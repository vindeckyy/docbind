# Macro API

Call `alpha.one()` and read `alpha.two` for the first independent group.

Call `beta.five()` for the second independent group.

Call `nested_three()` for the nested macro output.

Call `generated()` for the generated getter.

Call `generated_public()` for the generated public function.

Call `Config::default()` for defaults.

Call `Config::clone()` for a copy.
