# Code of conduct

## Scope

This policy covers issues, pull requests, discussions, and other project spaces.

## Expected behavior

- Discuss the code, not the person.
- Give reproducible examples when reporting a problem.
- Accept that maintainers may decline a change that expands scope or hurts precision.
- Respect privacy. Do not publish another person's private information.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or imagery.
- Publishing private information without consent.
- Deliberate disruption of issues or pull requests.

## Enforcement

Report conduct problems to the maintainer through GitHub. Use a private report if the repository offers one. Maintainers may edit or remove content, close threads, or block accounts.

This policy is informed by Contributor Covenant 2.1, with project-specific enforcement.
